# PLR-CMM levels (Table I of the PLR-CMM paper, verbatim)

Table I: Correspondence between each PLR-CMM level and the three variables of PDT (Purpose-Driven Trust)

| Level | Evolutionary State | Trustee | Purpose | Trust |
|---|---|---|---|---|
| L1 | Establish | Organize role assumptions | Purpose and data requirements | Understand legal regulations |
| L2 | Acquire | Define stakeholder roles | Context-dependent consent | Iteratively acquire consent |
| L3 | Expand | Institutionalize review systems | Review purpose alignment | Data management and security-by-design |
| L4 | Respond | Transact with data users | Match usage purposes | Return outcomes |
| L5 | Include | Expand ecosystem participants | Catalog as a common language | Trust chain through representatives |

Level names: L1 Trust Foundation, L2 Trust Building, L3 Trust Scaling, L4 Trust Reciprocation, L5 Trust Inclusion.

As the sequence of PLR-CMM levels denotes prerequisite dependencies rather than a chronological timeline, capabilities across multiple levels are often acquired concurrently instead of sequentially. Moreover, as shifts in purpose or target data necessitate reverting to lower levels for reacquisition, capability IDs from various levels appear in each period. Therefore, the overall maturity is determined by the collective set of acquired capabilities.
